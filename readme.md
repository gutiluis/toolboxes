# Toolboxes

__ **Currently under development** __

General-purpose automation tools and reusable code.

- [Bash](bash/)
- [C](c/)
- [C++](cpp/)
- [C# / .NET](dotnet/)
- [Go](go/)
- [Java](java/)
- [JavaScript](javascript/)
- [Perl](perl/)
- [PowerShell](powershell/)
- [Python](python/)
- [Ruby](ruby/)
- [Rust](rust/)
- [SQL](sql/)
- [Swift](swift/)
- [TypeScript](typescript/)


A collection of small, reusable tools and utilities for everyday scripting, automation, and development.

The project keeps tools **small, reusable, composable, command-line friendly, and easy to test**.

## Design Principles

* Small, focused utilities
* Reusable Python code
* Command-line friendly
* Minimal dependencies
* Standard library where practical
* Easy to test
* Composable tools
* Clear interfaces
* No unnecessary abstractions
